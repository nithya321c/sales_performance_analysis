# Data Dictionary

The dataset is **synthetic** and was generated for learning. It does not represent real customers or company performance.

| Column | Meaning | Example / type |
|---|---|---|
| Order ID | Unique transaction/order identifier in this practice dataset | ORD-000001 / text |
| Order Date | Date order was placed | YYYY-MM-DD / date |
| Ship Date | Date order shipped | YYYY-MM-DD / date |
| Customer ID | Synthetic customer key | CUST-0001 / text |
| Customer Name | Synthetic customer label | Customer 0001 / text |
| Segment | Customer group | Consumer, Corporate, Home Office |
| Country | Country | United States |
| City | City | Text |
| State | State | Text |
| Region | Broad sales region | West, East, Central, South |
| Product ID | Synthetic product identifier | Text |
| Category | Product category | Furniture, Office Supplies, Technology |
| Sub-Category | More detailed product group | Text |
| Product Name | Product label | Text |
| Sales | Net transaction sales after discount | Decimal currency units |
| Quantity | Number of units in the transaction | Integer |
| Discount | Discount fraction from 0 to 0.40 | Decimal |
| Profit | Transaction profit estimate; may be negative | Decimal currency units |
